# Petshop ClickPet - Fase 1

Projeto da disciplina **Fundamentos de Sistemas Web** (PUCRS - Análise e Desenvolvimento de Sistemas).

Site de um petshop fictício feito **somente com HTML**, sem CSS/Bootstrap e sem JavaScript (que serão usados nas próximas fases).

## Arquivo de ajuda - funcionalidades do site

| Página | Arquivo | O que tem |
|---|---|---|
| Início | `index.html` | Apresentação do petshop, atalhos para as páginas e um produto em destaque. |
| Produtos | `produtos.html` | 3 categorias (Alimentação, Higiene, Brinquedos e Acessórios), com 2 produtos cada, mostrando foto, descrição e valor. |
| Serviços | `servicos.html` | Tabela com os serviços (descrição, valor e se tem tele-busca). |
| Contato | `contato.html` | Endereço, telefone, e-mail, horários e formulário (ainda sem envio). |

Todas as páginas têm **cabeçalho** (logo, informações do petshop e menu de navegação), **corpo** e **rodapé** (autoria, contato e links).

## Como usar
Abra o `index.html` no navegador e use o menu no topo para navegar entre as páginas.

## Estrutura de pastas
```
index.html
produtos.html
servicos.html
contato.html
README.md
imagens/
```

## Observações
- As imagens são ilustrativas e podem ser trocadas por fotos reais.
- Nome, endereço, telefone e e-mail são fictícios.
